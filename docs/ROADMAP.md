# Roadmap

These are proposed directions, not implemented features or delivery commitments. Issues and small prototypes should establish scope before large changes.

## Near-term priorities

- English interface and a maintainable localisation system.
- Better keyboard navigation and screen-reader coverage.
- Validation on dedicated pen hardware and improved pressure handling.
- More regression coverage for long documents and annotation positioning.
- Signed Windows releases when signing infrastructure is available.

## Explore next

- Notebook folders and richer library organisation.
- Import and annotate existing PDFs.
- Multi-file LaTeX projects with explicit asset management.
- Safer annotation handling when source pagination changes.

## Research, not a promise

Handwritten mathematics recognition needs a separate evaluation of accuracy, privacy, model distribution and runtime cost. The current formula panel accepts typed LaTeX only.
