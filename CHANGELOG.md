# Changelog

## 1.0.0 — 2026-11-20

Initial public release of InkMath Paper Studio for Windows x64.

- Paper-centred workspace with notebook library, search, favourites and focus mode.
- Tectonic compilation, PDF.js preview and LaTeX source export.
- Handwritten-style body fonts, paper styles and ink colours.
- Russian and extended Cyrillic font fallback.
- Pen, highlighter, stroke eraser, lasso, rectangle and text annotations.
- Vector annotation export to PDF, local autosave and library backup.
- Editable probability and statistics example notebook.
- Pinned compiler setup, Windows build workflow and developer documentation.
